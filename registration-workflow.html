Grok 帳戶自動註冊完整流程

Grok API Pool 指南 · 附錄 B 詳細版
← 返回主指南

本頁完整說明「Grok 帳戶自動註冊系統」從 Cron 觸發到成功匯入 grok2api 的全流程。

包含每個步驟執行的 script、讀寫檔案、瀏覽器自動化、郵件驗證、Token 提取、帳戶儲存與 Admin API 匯入。

整體流程架構

Cron (04:00 / 16:00)
  ↓
~/.hermes/scripts/grok-pool-batch.sh
  ↓
~/grok-pool/cron-batch.sh 5
  ↓
~/grok-pool/grok-pool-register.sh 5 1
  ↓
  ├─ 產生 accounts_*.txt
  ├─ browser_runtime.py + DrissionPage（自動註冊 + 郵件驗證 + Token 提取）
  ├─ 解析 Token 並呼叫 grok2api Admin API 匯入
  └─ 寫入 logs/batch_*.log
  ↓
pool-status.py（每分鐘更新 status.json）
  ↓
儀表板顯示最新批次 + 配額

完整端到端流程（12 步驟）

1

Heremes Cron 觸發

執行檔：~/.hermes/scripts/grok-pool-batch.sh

每日在 04:00 及 16:00 由 Hermes cron 機制啟動，預設每批註冊 5 個帳戶。

讀取：無
產生：無
2

批次包裝執行

執行檔：~/grok-pool/cron-batch.sh

接收參數（預設 5），呼叫主註冊腳本，並將輸出寫入 log。

讀取：無
產生：logs/cron_*.log
3

主註冊腳本啟動

執行檔：~/grok-pool/grok-pool-register.sh

負責整個註冊流程的 orchestration，包含產生帳戶檔、呼叫瀏覽器自動化、解析 Token、呼叫 Admin API 匯入。

讀取：config、環境變數
產生：accounts_YYYYMMDD_HHMMSS.txt
4

瀏覽器自動化註冊

執行檔：~/grok-pool-register/browser_runtime.py + cpa_xai/browser_session.py

使用 DrissionPage 啟動 Chromium，前往 console.x.ai 進行註冊、處理郵件驗證、登入並提取 SSO Token。

讀取：config.json、proxy 設定
產生：瀏覽器 session、驗證郵件
5

郵件驗證處理

瀏覽器自動化會自動打開郵件驗證連結（或模擬點擊），完成帳戶啟用。

6

登入與 Token 提取

驗證成功後自動登入 console.x.ai，提取 SSO Token 存入 accounts_*.txt 的第 3 欄。

產生：accounts_*.txt（格式：email ---- password ---- token）
7

解析帳戶檔

grok-pool-register.sh 讀取 accounts_*.txt，解析出 email / password / token。

8

grok2api Admin API 登入

使用 admin 帳號登入 grok2api，取得 access token。

POST /api/admin/v1/auth/login
9

帳戶匯入 grok2api

呼叫 Admin API 的 import endpoint，將 console 及 web 帳戶分別匯入。

POST /api/admin/v1/accounts/import（multipart form）
10

寫入執行 Log

所有輸出寫入 logs/batch_*.log，包含成功 / 失敗 / 匯入數量。

11

健康監察更新

pool-status.py 每分鐘執行，更新 web/status.json，包含最新批次與配額。

12

儀表板顯示

系統監察頁每分鐘自動刷新，顯示最新批次結果與配額 gauge。

關鍵技術點

瀏覽器自動化
使用 DrissionPage + Chromium，自動處理註冊、郵件驗證、登入、Token 提取。cron 環境需額外掃描 Chromium 路徑。
帳戶儲存格式
email ---- password ---- SSO_TOKEN（三欄以 ---- 分隔）
grok2api Admin API 匯入
必須使用 multipart form 上傳檔案，raw body 會回 invalidAuthFile。

各步驟對應原始碼檔案

步驟主要檔案
1. Cron 觸發~/.hermes/scripts/grok-pool-batch.sh
2. 批次包裝~/grok-pool/cron-batch.sh
3. 主註冊腳本~/grok-pool/grok-pool-register.sh
4-6. 瀏覽器自動化~/grok-pool-register/browser_runtime.py
~/grok-pool-register/cpa_xai/browser_session.py
7-9. 解析與匯入grok-pool-register.sh（內建 Admin API 呼叫）
10. Log 寫入logs/batch_*.log
11. 健康監察~/grok-pool/pool-status.py
